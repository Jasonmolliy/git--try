# 点靶训练 · Aim Trainer

一个纯前端的 FPS 风格点靶小游戏，单个 `index.html`，无需安装任何依赖，双击即可在浏览器打开。

在线游玩（开启 GitHub Pages 后）：<https://jasonmolliy.github.io/git--try/>

## 玩法

- 鼠标控制准星，左键点击靶子射击
- 无尽模式：分数越高，靶子越小、存活时间越短、出现越快、数量越多，并会开始漂移
- 漏掉靶子（靶子生命环走完）会扣 10 点生命，生命归零游戏结束
- 连续命中累计连击，每 12 连击回复 5 点生命
- 结算显示分数、最高分、命中率、最高连击、坚持时间和漏靶数
- 最高分和灵敏度设置保存在浏览器本地

## 灵敏度

开始界面的滑块可调 **鼠标灵敏度（0.4× ~ 3.0×）**：数值越大，同样的鼠标移动会让准星移动越远，类似游戏里的 DPI / 灵敏度设置。

游戏过程中可以按 `[` 和 `]` 实时微调，不用暂停。

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标移动 | 移动准星（开始后鼠标会被指针锁定） |
| 左键 | 射击 |
| `[` / `]` | 降低 / 提高灵敏度 |
| `Esc` | 暂停并解锁鼠标 |

手机端会自动进入触屏模式，直接点靶子即可。

## 本地运行

直接双击 `index.html`，或在该目录执行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 部署到 GitHub Pages

1. 仓库页 → `Settings` → `Pages`
2. `Source` 选择 `Deploy from a branch`
3. `Branch` 选择 `main`，目录选 `/ (root)`，点 `Save`
4. 等待约 1 分钟，访问 <https://jasonmolliy.github.io/git--try/>
